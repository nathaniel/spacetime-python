Help for Spacetime

View this help file in your browser

Spacetime is a computer program for developing an intuition for special relativity. It can be used to analyze exercises and projects or to explore relativistic motion independently.

The application has two synchronized displays: the Highway shows a snapshot of objects moving at different velocities, while the Spacetime diagram plots their positions and worldlines over time. The displays share the scenario, horizontal scale, and horizontal pan, so an object or event can be investigated in whichever view is most convenient. Objects, events, and scenario comments are edited in the dockable Tables panel; this Help page is available in the dockable Help panel. The application is designed to be usable after a few minutes of practice, with this page available for less familiar operations.

Preface

Coordinates use units where the speed of light is 1. Position is horizontal and time increases upward. The original/master frame is the frame in which scenario coordinates are stored. Changing the reference frame changes the displayed coordinates without rewriting the underlying scenario.

Clocks accumulate proper time along their piecewise-constant-velocity worldlines. A light flash always travels at the speed of light, with beta exactly -1 or +1; programming a flash changes its direction rather than its speed. Events mark occurrences in spacetime, and decorations such as intervals, light cones, and invariant hyperbolas help compare events geometrically.

The Highway display

The Highway represents a snapshot of a movie of the objects. Changing the current time changes the snapshot. Objects on the center strip have zero velocity. Objects above the center move right; objects below it move left. The top and bottom lanes correspond to the speed of light and are reserved for light flashes.

The vertical ruler shows β, velocity as a fraction of the speed of light. The scale runs from +1 at the top through 0 at the center to -1 at the bottom and is intentionally nonlinear, allowing more useful velocities near the speed of light to fit on screen. The adjacent γ scale shows the time-stretch factor:

γ = 1 / √(1 - β2)

Objects above the center move right, and objects below the center move left. The center lane has beta 0. The top and bottom lanes are the light-speed lanes and are reserved for light flashes. The Highway convention is like a modified British motorway: slow lanes are near the center strip and faster lanes are near the edges.

Moving clocks run slow by the factor γ, and moving rods are contracted by the factor γ along their direction of motion. Gamma is always positive, is 1 at beta 0, and grows without bound as beta approaches either light-speed lane.

The Spacetime diagram display

The horizontal axis represents position and the vertical axis represents time. A worldline traces the trajectory of an object through spacetime. Objects shown on the Highway appear as worldlines here.

The thick blue line is the line of simultaneity for the current time in the current reference frame. Events simultaneous at that time lie on this line. The current time is shown in the status bar. The Highway and diagram share their horizontal scale and pan position. A vertical red or green marker in the Highway can indicate a boundary or programmed velocity-change event at the current time.

Worldlines may be straight or piecewise straight. A kink represents a programmed change in beta. Boundary events limit the portion of a worldline that is displayed; they can be labeled and annotated in the Event table but their coordinates are controlled by the object.

Quick tutorial: a trip to Alpha Centauri

This tutorial creates a trip from Earth to Alpha Centauri and back. The bundled scenario scenarios/Trip to Alpha.sce contains the completed example.

If you make a mistake, use Undo from the Edit menu or the platform-standard Undo shortcut. Undo restores the related object and event changes together.

1. Create the Earth clock

Start with the default clock, or choose Edit → Create Clock. Use the Objects table to change its label to Earth and enter a note. Notes appear in hover details in the status bar.

Python Spacetime default scenario.

2. Create the Alpha Centauri clock

Right-click an empty Highway position and choose Create clock. Place it four light years from Earth, then adjust its position or beta in the Objects table if needed. In the Objects table, rename the new clock to Alpha and add a note such as This is the star that the astronaut travels to.

The Objects table edits labels, position, beta, gamma, readings, and notes.

3. Create the rocket

Create another clock at position 0. Set its gamma factor to 2, then label it Rocket and add a note. The table accepts beta and formats the corresponding gamma value.

Object notes are visible in the table and hover details.

4. Create the departure event

At the current time, right-click the rocket and choose Set birth here and now. This creates a generated boundary event. Select the Events tab to edit its label and note.

The Events table displays the departure event.

5. Create the turning event

Advance time with the Up key or the spacetime diagram scroll gesture until the rocket intersects Alpha. Right-click the intersection and choose Create event. Generated velocity-change events receive labels such as Rocket-Δβ1.

The turning event is visible in the Events table.
The Highway view at the turning time.

6. Program the rocket to turn

At the turning time, right-click the rocket and choose Program. Drag it to a lane with gamma 2 in the opposite direction, or enter the new beta in the Objects table. A programmed object is shown in green until the edit is completed.

The programmed rocket is highlighted in green.

Dragging or editing an object outside Program mode redefines its worldline and removes its birth, termination, and programmed velocity-change events.

7. Create the arrival event

Advance time until the rocket meets Earth. Create an event at the intersection and label it Arrival. Then choose Set termination here and now on the rocket.

The completed trip and its events.

8. Compare reference frames

Use Reference frame to set beta or transform up and down. Return to original frame restores the original coordinates. The underlying scenario remains in the original frame while displayed coordinates change.

The same scenario in a different reference frame.

9. Compare simultaneity in the outbound and inbound frames

To reproduce the classic twin-paradox comparison, set the time near the turnaround, use Jump to object on the rocket, and locate the intersection of the Earth's worldline with the blue simultaneity line. Use Create event there and label the event S1. Return to the original frame, jump to the rocket again after the turnaround, and repeat the operation to create S2. The two events are different because simultaneity depends on the reference frame.

10. Comment and save

Use the Comments tab in the Tables panel to add scenario notes. Choose Scenario → Save or Save As to write a Spacetime scenario .sce file.

Hover details include object notes in the status area.

Congratulations. You have created a complete spacetime scenario.

Instructions on how to use the software

Animation and time

Use Up and Down to advance or rewind time by 0.1. Use the platform modifier with Up or Down for steps of 1.0. The spacetime diagram also responds to vertical wheel or two-finger scrolling; the Highway responds to vertical scrolling by transforming the reference frame. Time advances to the next event when one lies between regular time steps. Click a view before using keyboard navigation so it has focus.

Creating objects

Right-click an empty area of the Highway and choose Create clock or Create light flash. Drag the new object or edit its position and beta in the Objects table. A manual position or beta change clears that object's programmed worldline and boundary events. The Edit menu also provides dialogs for creating a clock or light flash at explicit coordinates.

Deleting objects

Right-click an object in either diagram or its row in the Objects table and choose Delete.

Creating events

The Python editor creates free events from an empty area of the spacetime diagram or through the Edit menu's Create Event action. A diagram click creates the event at the snapped displayed coordinates and the menu action creates it at the entered position and current time. Free events can be dragged and edited in the Events table. Imported Spacetime scenario files may also contain events fixed at an intersection or attached to a worldline; those events remain constrained and their coordinates are read-only in the table.

Deleting events

Right-click an event in the spacetime diagram or its row in the Events table and choose Delete. Generated boundary and velocity-change events are managed by their object actions.

Creating spacetime intervals

Right-click an event and choose Construct → Spacetime interval to . . ., then click a second event. The decoration shows whether the interval is spacelike (S), timelike (T), or lightlike (L), its invariant value, and Δx and Δt. The interval updates when either defining free event moves. Delete it from its context menu. Press Esc or click empty space to cancel an unfinished selection.

Creating invariant hyperbolas

Right-click an event and choose Construct → Invariant hyperbola. The decoration follows the event as it moves and can be deleted from its own context menu.

Creating light cones

Right-click an event and choose Construct → Light cone. The light cone follows the event and can be deleted from its own context menu.

Jumping to objects

Right-click an object in the Highway or its row in the Objects table and choose Jump to this object. The display changes to that object's rest frame.

Transforming the reference frame

Transform up and Transform down apply a relative beta of +0.05 or -0.05 to the current frame. Use the Reference frame menu or Shift+Up and Shift+Down. Shift+0 returns to the original frame.

Shifting the view

Drag an empty area horizontally, use Left and Right, or use the platform modifier with Left and Right for a larger movement. The Highway and spacetime diagram remain synchronized. The horizontal view range is saved in the scenario.

Programming objects

Clocks and flashes can change velocity at programmed events. Right-click an object in the Highway and choose Program, then drag it to a new lane or edit its beta. The object is green while it is being programmed. For flashes, programming changes the direction between beta -1 and +1.

Entering a new programmed beta removes a termination after that point and continues the programmed worldline. If a new programmed change is entered before later programmed changes, those later changes are discarded. Changing an object manually outside Program mode removes its programmed changes, boundary events, and returns its worldline to the newly edited state. Click elsewhere in the Highway to finish programming and return the object to its normal color.

Setting birth and termination

Right-click an object in the Highway and choose Set birth here and now or Set termination here and now. Once set, the corresponding action becomes Cancel birth or Cancel termination. The generated boundary events appear in the Event table and can be relabeled or given notes, but their coordinates cannot be dragged or edited. Birth and termination are also available from the Objects table context menu.

Zooming in and out

Choose View → Zoom in or Zoom out, use Plus or Minus, or pinch on a trackpad. Both displays share the horizontal scale.

Using the Object and Event tables

The tables list all objects and events. White cells are editable; gray cells are read-only. Double-click or select a white cell and type to edit it. Object tables show label, position, beta, gamma, clock reading, and notes. Gamma is formatted from beta; a clock's reading is calculated and read-only. Right-click a row for its context menu. The Event table supports horizontal scrolling, and its Note column resizes to fit its content. Coordinates for fixed and worldline-attached events are gray and read-only.

Using comments

Choose the Comments tab in the Tables panel to write scenario comments. Comments are saved with the scenario and preserve multiline text. Use comments for assumptions, units, frame choices, or a description of the experiment so that a saved scenario remains understandable when reopened.

Menus, files, and undo

The Scenario menu creates a new scenario, opens an existing Spacetime scenario .sce file, saves the current scenario, saves under a new name, and quits. Scenario files preserve object and event data, programmed worldlines, decorations, comments, and the synchronized horizontal view range. Unknown compatible properties are retained where possible.

The Edit menu provides Undo and Redo, Create Event, Create Clock, and Create Light Flash. Object drags, boundary changes, programming, event creation and deletion, and decorations are recorded so Undo reverses a complete logical change rather than leaving related events behind. Table-cell edits apply directly to the scenario; use the saved snapshot or edit the cell again if one of those changes needs to be corrected. If a mistake is made, use Undo where available instead of manually rebuilding the scenario.

The Reference frame menu sets a beta, transforms up or down, or returns to the original frame. The Coordinates menu sets or steps time, sets time to zero, and centers the view on an x coordinate. The View menu zooms, pans, and changes the application font size. Help opens this dockable page with F1 and provides About.

Keyboard navigation uses Up and Down for time, Left and Right for horizontal movement, Shift+Up and Shift+Down for frame changes, Shift+0 for the original frame, the platform modifier with 0 to set time to zero, and Plus or Minus for zoom. On macOS the modifier is Cmd; on Windows and Linux it is Ctrl.

A little bit of history

The original Spacetime program was developed at the Massachusetts Institute of Technology and funded through MIT Project Athena in the late 1980s. MIT undergraduates worked on the original program under the supervision of Edwin F. Taylor for use in a special-relativity course. The program was first developed for IBM PC computers, and Apple Computer provided support for a Macintosh version. The Java version is a later reworking of those essential ideas; this Python version continues the reimplementation with a contemporary Qt interface while retaining Spacetime scenario .sce files.
